# Produtos - React

Projeto desenvolvido em React para praticar navegação entre páginas, rotas dinâmicas e consumo de API.

## 🚀 Tecnologias

- React
- JavaScript
- React Router DOM
- CSS
- Vite
- Fetch API

## 📌 Funcionalidades

- Listagem de produtos
- Página individual de cada produto
- Rotas dinâmicas com React Router
- Consumo de API
- Página de contato

## 🌐 API

Ranek API:
